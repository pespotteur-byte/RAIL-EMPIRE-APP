RAIL EMPIRE v1.1.95 — CATALOGUE NAME DEDUP
================================================

Objectif de cette build
-----------------------
Première passe de remise au propre du catalogue matériel : supprimer les milliers de noms d'affichage identiques sans toucher aux identifiants ni aux caractéristiques gameplay.

Résultat
--------
- Catalogue total : 36 307 entrées.
- IDs avant/après : strictement identiques et tous uniques.
- 3 256 groupes de noms dupliqués avant la passe.
- 13 592 fiches appartenaient à un groupe de nom dupliqué.
- 10 336 répétitions surnuméraires de noms.
- 13 582 noms effectivement modifiés.
- 0 groupe de nom dupliqué après normalisation espace/casse.
- 0 autre champ catalogue modifié dans cette passe.

Politique de renommage
----------------------
- Le nom de famille/classe reste toujours au début, pour conserver la recherche habituelle.
- Les variantes sont distinguées uniquement à partir de données déjà présentes : série, livrée/description, variante MLG, chemin/archive MLG.
- Aucun suffixe artificiel du type « copie 1 », « copie 2 » n'est utilisé.
- Quand deux sources sont réellement impossibles à distinguer autrement, l'identifiant documentaire/catalogue est utilisé en dernier recours.
- Aucun ID n'est supprimé à J-4 de la release afin de ne pas casser les rames/sauvegardes existantes.

Exemples
--------
BB 26000 -> BB 26000 — Sybic — Livre d'origine / Livrée FRET / Livrée fantôme / variantes Carmillon, etc.
BB 22200 -> distinction petites/grandes cabines et livrées.
X 73500 -> distinctions de livrées/régions/variantes.
Les anciens noms très génériques A / B / AB récupèrent une famille/variante documentaire.
