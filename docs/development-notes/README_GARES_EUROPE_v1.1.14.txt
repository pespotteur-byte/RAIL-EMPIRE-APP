RAIL EMPIRE v1.1.14 — RAILNET EUROPE GAMEPLAY NATIVE
=====================================================

DEMARRAGE
---------
1. Extraire le ZIP dans un dossier neuf.
2. Ouvrir index.html.
3. Jouer.

Aucun .cmd. Aucun préparateur. Aucun téléchargement.

IMPORTANT : LES GARES SONT DEJA GAMEPLAY
-----------------------------------------
Les 17 817 gares ferroviaires européennes sont directement créées dans le monde Rail Empire comme des objets Station complets.
Il n'existe plus d'étape "référence -> activation" pour RailNet Europe.

Dès l'entrée en partie, elles peuvent être :
- sélectionnées comme gares normales ;
- utilisées dans les lignes et horaires ;
- reliées par des voies ;
- éditées ;
- utilisées par les systèmes de quai et d'exploitation.

SAUVEGARDES
------------
Le jeu reconstruit automatiquement le socle des 17 817 gares depuis les fichiers locaux avant de charger une sauvegarde.
Une gare native intacte n'est donc pas recopiée dans le save.
Seules les modifications/suppressions du joueur sont enregistrées.
