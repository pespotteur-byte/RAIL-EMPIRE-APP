RAIL EMPIRE · RC22 FULL · Aide au fond de carte

Le vrai fond OpenStreetMap

Dans la LiveMap, cochez OSM original : routes, bâtiments, cours d’eau et noms proviennent du fond standard OpenStreetMap Carto, dans ses couleurs d’origine. Le filtre ORM ajoute les voies ferroviaires indépendamment. Décocher OSM original retrouve le style sombre ; Satellite reste disponible séparément.

Le choix OSM désactive le satellite et son composite nocturne. Il est conservé lors de l’entrée en suivi GPS ; la météo visuelle peut toujours ajouter son voile d’atmosphère. Le bouton Afficher OSM original dans le panneau du fond rétablit également cette source après une configuration personnalisée.

Double-cliquez simplement sur index.html

  1. Conservez un export de votre partie et l’ancienne version. Fermez les anciens onglets.
  2. Extrayez le ZIP FULL dans un dossier, puis double-cliquez sur index.html. Le jeu s’ouvre directement dans le navigateur en file://.
  3. Dans la LiveMap, cochez OSM original. Aucun programme, extension, terminal ou serveur local n’est nécessaire.

Pour les fichiers HTML locaux, le chargeur envoie X-Requested-With: RailEmpire avec la demande HTTPS des tuiles. Cette méthode est documentée sur la page OSM consacrée au référent, précisément pour file://. Le nom désigne réellement notre application ; aucun faux référent, faux User-Agent ni proxy n’est ajouté. En HTTP/HTTPS, le navigateur continue d’envoyer son véritable référent.

Une connexion Internet reste nécessaire pour obtenir les tuiles non présentes dans le cache. Le navigateur effectue une vérification CORS avant d’envoyer cet en-tête personnalisé. Si elle échoue, RE affiche une erreur et ne tente pas une demande anonyme en secours.

Ne videz pas les données du site. Les sauvegardes ouvertes en HTTP local et celles ouvertes en file:// peuvent être séparées ; même un changement de chemin de fichier peut changer leur visibilité selon le navigateur. Exportez depuis l’ancienne ouverture et importez depuis la nouvelle si nécessaire. Le comportement du stockage local file:// dépend du navigateur.

LANCER_RE.cmd et les anciens outils HTTP restent archivés pour compatibilité, mais ils ne sont ni appelés ni nécessaires au lancement HTML. Les anciennes notices de livraison décrivent leur version historique ; cette notice RC22 remplace leurs consignes OSM.

403, saturation, réseau : pas de contournement

Une nouvelle version ne lève pas une interdiction du fournisseur. Un HTTP 401/403 lisible, ou un en-tête x-blocked signalant un refus (même avec HTTP 200), arrête le service ; le blocage mémorisé est conservé. Corrigez la cause et vérifiez que l’accès est autorisé avant une reprise manuelle. Les quinze minutes minimales imposées par le client ne sont pas une promesse de déblocage. N’utilisez pas de faux référent, d’identité usurpée, de rotation de domaines, d’IP ou de proxy pour contourner un refus.

Un HTTP 429 respecte Retry-After lorsqu’il est lisible, avec au moins une minute d’attente. Les autres erreurs sont temporisées. Une erreur CORS sans statut lisible reste signalée comme une erreur réseau/CORS : elle n’est pas inventée comme étant une 403. Les tuiles déjà décodées peuvent rester affichées pendant une suspension.

Règles intégrées au chargeur

  • URL standard canonique : https://tile.openstreetmap.org/{z}/{x}/{y}.png, sans clé ni paramètre anti-cache. Le navigateur conserve son User-Agent réel. Les pages HTTP envoient leur référent via strict-origin-when-cross-origin ; les fichiers HTML utilisent X-Requested-With: RailEmpire.
  • Cache HTTP normal (cache: default), sans no-cache envoyé par l’application. Le navigateur gère les en-têtes d’expiration et la revalidation. Le cache des images déjà décodées est réutilisé ; aucune copie persistante supplémentaire des tuiles n’est ajoutée aux sauvegardes.
  • Seulement les tuiles de la vue affichée ; annulation des demandes devenues hors champ ou provenant d’une carte fermée. Pas de téléchargement de région hors ligne, de parcours préalable d’un sillon ou de collecte de plusieurs niveaux de zoom.
  • Quatre chargements simultanés au plus par service, partagés entre cartes de la même page. C’est une limite prudente du jeu, pas un quota officiellement garanti par OSM. Plusieurs onglets peuvent avoir chacun leurs chargements : évitez les sessions dupliquées.
  • Zoom source OSM limité à 19 ; les zooms visuels supérieurs agrandissent ces pixels, sans inventer des tuiles natives de niveau 20 ou 30.
  • Attribution lisible et lien de licence sur la LiveMap, le SC et les autres éditeurs utilisant ce chargeur. Aucun fournisseur alternatif n’est activé automatiquement.
